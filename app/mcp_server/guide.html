开始连接

三步接入你的智能体

客户端的菜单名称可能不同，通常位于“工具”“连接器”或“MCP Servers”。你只需要服务地址和管理员提供的访问 Token。

STEP 01

添加远程 MCP

新建一个名为“关系期刊知识服务”的 Streamable HTTP MCP。

STEP 02

填写地址与 Token

粘贴下方地址，鉴权选择 Bearer Token。不要把 Token 写进聊天消息。

STEP 03

保存并测试

看到期刊工具列表后，直接用自然语言提问，无需记住工具名称。

作者使用手册

从“适不适合”走到“证据是什么”

告诉智能体目标期刊、研究主题和你希望解决的问题。稿件分析建议提供标题、摘要和关键词，而不是只给一个宽泛主题。

投稿内容匹配

判断研究是否贴近期刊历史内容

获得匹配强弱、相近主题和代表论文，但不把结果当作录用预测。

请使用关系期刊知识服务，评估以下研究与 ZDXBNXB 历史内容的匹配程度，并用相似论文解释原因。标题：……；摘要：……；关键词：……
查找相似论文

为写作与投稿准备相关阅读

可限定年份和阅读目标，并要求返回 DOI 与在线链接。

请在 ZDXBNXB 中查找与“水稻抗病机制”相近的论文，优先近十年，列出标题、作者、年份、DOI、在线链接和推荐理由。
主题学习

了解一个方向在本刊的发展

查看年度变化、代表主题和论文证据，避免只看搜索结果数量下结论。

请分析 ZDXBRWB 中“数字经济”主题近十年的发文趋势，并列出趋势变化最明显阶段的代表论文。
作者与机构

查看本刊范围内的研究画像

同名时先确认候选；画像只代表作者或机构在本刊收录数据中的活动。

请在 ZDXBNXB 中解析作者“张三”，如果存在多个候选先让我确认；确认后总结其本刊论文、主题和合作关系，并附共同论文证据。

编辑使用手册

用统一口径观察选题、作者与结构变化

编辑问题应明确期刊、时间范围、比较对象和排序依据。需要统计时，让智能体调用聚合和趋势工具，不要自行汇总展示列表。

选题趋势

分析年度发文变化

按统一公式返回年度序列、斜率和上升、稳定或下降判断。

请分析 ZDXBNXB 2016—2025 年“生物育种”主题的发文趋势，说明统计口径，并提供年度数据和代表论文。
时期比较

比较两个阶段的主题结构

识别新增、消失、增强和减弱主题，并保留各阶段范围。

比较 ZDXBRWB 2016—2020 年与 2021—2025 年的主题结构，列出增强、减弱、新增和消失主题及代表论文。
贡献者分析

按明确业务口径排序

可以按发文量、持续性、主题覆盖或合作强度排序，但不能解释为学术质量排名。

请按发文持续性排序 ZDXBNXB 近十年的作者，给出前十名、计算依据和每位作者的年度活动证据。
合作结构

查看共同署名网络

通过共同论文查看作者或机构的连接，不能推断导师、团队或现实组织关系。

请分析 ZDXBRWB 中“共同富裕”主题相关作者的合作网络，列出主要连接及支撑每条连接的共同论文。

结果边界

正确理解结果，比得到结果更重要

服务回答的是“本刊历史数据中有什么”，不是对现实世界全部学术活动的完整判断。

可以支持

  • 检索本刊收录论文并返回 DOI、作者和在线 URL
  • 按明确口径统计发文、主题和贡献者
  • 用共同论文证明作者或机构的共现关系
  • 比较稿件内容与本刊历史主题的匹配程度

不能支持

  • 投稿匹配不代表录用概率、审稿结果或学术质量
  • 不能证明研究在全球范围内是否首次或绝对创新
  • 共同署名不能证明导师、团队或组织隶属关系
  • 没有检索结果不代表现实世界中不存在相关研究

排查问题

连接失败时先看这里

绝大多数问题来自地址、鉴权或客户端协议支持。不要在聊天窗口公开 Token。

提示 401 Unauthorized

服务已收到请求，但 Bearer Token 缺失或不正确。重新从管理员处获取 Token，确认前后没有空格，并把它填写到客户端的鉴权或 Secret 字段中。

连接成功但看不到期刊工具

确认客户端支持 Streamable HTTP MCP，然后断开并重新连接，让客户端重新执行初始化和工具发现。若客户端只支持本地 STDIO MCP，则不能直接连接此远程地址。

智能体没有使用期刊服务

在问题开头明确写“请使用关系期刊知识服务”，并提供期刊代码。检查当前会话是否允许该 MCP 工具；部分客户端会在首次调用时请求授权。

语义检索返回 partial 或暂时不可用

这通常表示语义服务降级。仍可改用明确的年份、主题、作者、机构或 DOI 条件执行结构化检索；回答中应保留降级说明。
