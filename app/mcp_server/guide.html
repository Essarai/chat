开始连接

三步接入你的智能体

客户端的菜单名称可能不同，通常位于“工具”“连接器”或“MCP Servers”。你只需要服务地址和管理员提供的访问 Token。

STEP 01

添加远程 MCP

新建一个名为“期刊知识服务”的 Streamable HTTP MCP。

STEP 02

填写地址与 Token

粘贴下方地址，鉴权选择 Bearer Token。不要把 Token 写进聊天消息。

STEP 03

保存并测试

作者使用手册

先说清任务，再让证据回答

先选择目标期刊和任务：投稿前判断内容匹配、查找文献、了解主题变化，或查看作者与机构。稿件匹配只需提供标题、摘要和关键词，并要求结论附论文证据与数据边界。

投稿前判断

看内容匹配，不预测录用

要求分别说明“匹配在哪里、差异在哪里、还应补查什么”，并用本刊历史论文支撑判断。

请使用期刊知识服务，评估以下研究与 ZDXBNXB 历史内容的匹配程度。请分别说明匹配点、差异点和建议补查的方向，列出支撑判断的相似论文；不要预测录用概率。标题：……；摘要：……；关键词：……
查找相似论文

把检索结果变成阅读清单

说明研究问题、时间范围和阅读目的，让结果按相关性组织，并返回 DOI 与在线链接。

请在 ZDXBNXB 中查找近十年与“水稻抗病机制”相关的论文，按与研究问题的相关性排序。每篇列出标题、作者、年份、DOI、在线链接和推荐理由，并说明本次检索的数据范围。
主题学习

理解主题如何变化

要求分阶段解释年度变化、主题侧重和代表论文，不用单一检索数量代替趋势分析。

请分析 ZDXBRWB 中“数字经济”主题近十年的发展变化。请划分主要阶段，说明各阶段的发文数量、主题侧重和变化依据，并列出代表论文。
作者与机构

先消歧，再看本刊研究画像

遇到同名作者或相似机构名时先确认对象；画像只反映其在本刊收录数据中的活动。

请在 ZDXBNXB 中解析作者“张三”，如果存在多个候选先让我确认；确认后总结其本刊论文、主题和合作关系，并附共同论文证据。

编辑使用手册

先固定统计口径，再比较变化

编辑问题应明确期刊、时间窗口、分析对象、比较维度和输出格式。要求智能体返回完整聚合结果、计算依据和代表论文，避免从有限展示列表中自行推断总体趋势。

选题观察

用年度序列识别变化

先确认主题边界和时间窗口，再查看年度数量、变化方向、阶段拐点与论文证据。

请分析 ZDXBNXB 2016—2025 年“生物育种”主题的发文变化。先说明主题与统计口径，再提供完整年度数据、阶段划分、变化依据和各阶段代表论文。
时期比较

用同一口径比较两个阶段

固定主题识别方法和分母，区分增强、减弱、新增与暂未出现，并保留两阶段数据范围。

请用同一统计口径比较 ZDXBRWB 2016—2020 年与 2021—2025 年的主题结构。列出增强、减弱、新增和暂未出现的主题，给出数量与占比变化，并附代表论文。
贡献者画像

先定义“贡献”，再排序

可按发文量、持续性、主题覆盖或合作活跃度观察，但不能把业务排序解释为学术质量排名。

请按“近十年有发文的年份数”衡量持续性，对 ZDXBNXB 作者排序。给出前十名、并列处理方式、计算依据和每位作者的年度发文证据；不要解释为学术质量排名。
合作网络

用共同论文解释连接

每条作者或机构连接都应回到共同论文；共同署名不能证明导师、团队或现实组织关系。

请分析 ZDXBRWB 中“共同富裕”主题相关作者的共同署名网络。列出主要连接、合作次数和支撑每条连接的共同论文，并明确该结果不代表导师或组织关系。

结果边界

正确理解结果，比得到结果更重要

服务回答的是“本刊历史数据中有什么”，不是对现实世界全部学术活动的完整判断。

可以支持

  • 检索本刊收录论文并返回 DOI、作者和在线 URL
  • 按明确口径统计发文、主题和贡献者
  • 用共同论文证明作者或机构的共现关系
  • 比较稿件内容与本刊历史主题的匹配程度

不能支持

  • 投稿匹配不代表录用概率、审稿结果或学术质量
  • 不能证明研究在全球范围内是否首次或绝对创新
  • 共同署名不能证明导师、团队或组织隶属关系
  • 没有检索结果不代表现实世界中不存在相关研究

排查问题

连接失败时先看这里

绝大多数问题来自地址、鉴权或客户端协议支持。不要在聊天窗口公开 Token。

提示 401 Unauthorized

服务已收到请求，但 Bearer Token 缺失或不正确。重新从管理员处获取 Token，确认前后没有空格，并把它填写到客户端的鉴权或 Secret 字段中。

连接成功但看不到期刊工具

确认客户端支持 Streamable HTTP MCP，然后断开并重新连接，让客户端重新执行初始化和工具发现。若客户端只支持本地 STDIO MCP，则不能直接连接此远程地址。

智能体没有使用期刊服务

在问题开头明确写“请使用期刊知识服务”，并提供期刊代码。检查当前会话是否允许该 MCP 工具；部分客户端会在首次调用时请求授权。

语义检索返回 partial 或暂时不可用

这通常表示语义服务降级。仍可改用明确的年份、主题、作者、机构或 DOI 条件执行结构化检索；回答中应保留降级说明。
